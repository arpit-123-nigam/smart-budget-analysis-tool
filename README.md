# Smart Budget Analysis Tool with Predictive Analytics

A desktop-based personal finance management application 
built with Python and CustomTkinter.

## Features
- Secure login with Bcrypt encryption
- SQLite database storage
- Expense tracking with categories
- Visual charts (Pie + Bar)
- AI/ML based spending predictions
- Budget goal tracking with alerts
- Multi-format export (CSV, JSON, TXT, PDF)
- Multi-user support

## Tech Stack
Python 3 | CustomTkinter | SQLite | 
Pandas | Scikit-learn | Matplotlib | Bcrypt

## How to Run
pip install customtkinter matplotlib pandas 
scikit-learn plotly bcrypt fpdf2

python main.py
